# Formação Engenharia de IA 2026–2027

Repositório oficial de estudos, exercícios e projetos da formação em **Engenharia de IA Aplicada**.

**Período:** 19/10/2026 a 16/04/2027  
**Aluno:** Thomas  
**Carga principal:** segunda a sexta, 08:00–12:00  
**Bloco complementar:** segunda a sexta, 14:00–18:00 (opcional)  
**Revisões:** sábado e domingo

## Objetivo

Construir uma base sólida de engenharia de software e evoluir até aplicações completas com IA, passando por Python, Git, APIs, SQL/PostgreSQL, FastAPI, LLMs, RAG, automação, Docker, deploy, testes e portfólio.

## Estrutura

- `01-python-logica/` — fundamentos de Python, lógica, exercícios e projeto do módulo.
- `02-git-apis-sql-postgresql/` — versionamento, HTTP, APIs REST, SQL e banco de dados.
- `03-fastapi-backend-llms/` — backend, FastAPI, PostgreSQL e integração com modelos de linguagem.
- `04-rag-embeddings-busca-vetorial/` — embeddings, chunking, retrieval, bancos vetoriais e RAG.
- `05-n8n-docker-deploy-seguranca/` — automação, containers, Linux, deploy e segurança básica.
- `06-projeto-final/` — aplicação final integrada e documentação técnica.
- `exercicios-semanais/` — exercícios individuais e miniavaliações.
- `projetos/` — projetos práticos selecionados para portfólio.
- `anotacoes/` — resumos, erros recorrentes e aprendizados importantes.

## Método de estudo

1. Revisão ativa curta.
2. Explicação teórica.
3. Demonstração.
4. Prática guiada.
5. Exercício individual sem solução pronta.
6. Correção.
7. Registro de erros e aprendizados.

## Regra de uso de IA

A IA pode atuar como tutora: explicar conceitos, dar pistas, revisar raciocínio e ajudar a depurar erros. Em exercícios avaliativos e provas, a solução deve ser desenvolvida pelo aluno.

`FastAPI + PostgreSQL + IA/RAG + automação + Docker + deploy`
